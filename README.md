# 🏂 전체적인 흐름

1. 사용자로부터 문자열을 입력받는다.
2. 구분자 형식에 대하여 확인한다.
3. 잘못된 값을 입력한 경우 에러를 발생시킨 후 종료한다.
4. 입력받은 문자열에서 구분자를 기준으로 분리한 각 숫자의 합을 출력한다.

```
덧셈할 문자열을 입력해 주세요.
1,2:3
결과 : 6
```

# 🔧 구현할 기능 목록

- [x] 덧셈할 문자열을 입력 받는 문구를 출력한다.
- [x] 사용자로부터 문자열을 입력받는다.
    - [x] 양의 정수만 포함되었는지 확인한다.
    - [x] 올바른 구분자만 포함되었는지 확인한다. `( , or : )`
    - [x] 커스텀 구분자의 시작 문자열이 포함되었는지 확인한다.
    - [x] 커스텀 구분자 형식을 검증한다.
- [x] 잘못된 값이 입력된 경우, `IllegalArgumentException` 을 발생시킨 후 종료한다.
- [x] 구분자를 기준으로 숫자만 분리한다.
- [x] 각 숫자의 합을 구한다.
- [x] 결과를 출력한다.

# 💣 문제 조건 구체화

### 문자열 입력 및 기본 구분자

- 정수형 최대 범위를 넘는 값이 입력값으로 들어왔을 경우 -> `입력값이 정수형 최대 범위를 초과했습니다.`
- 기본 구분자(쉼표, 콜론) 이외에 다른 문자(공백 포함)가 포함된 경우 **ex) "1, ,2:3" -> `기본 구분자와 일치하지 않는 문자가 존재합니다.` 

### 커스텀 구분자

- 입력된 커스텀 구분자와 기본 구분자 이외에 다른 문자가 존재할 경우 -> `기본 구분자와 일치하지 않는 문자가 존재합니다.` (기본 구분자와 커스텀 구분자 혼용 허용 및 -는 기본적으로 음수가 아닌 구분자가 아닌 문자로 간주)
- "//"와 "\n" 사이에 **문자열**이 위치할 경우  **ex) //;;?\n** -> `잘못된 커스텀 구분자 형식입니다.` (문자열은 구분자로 허용하지 않는다.)
- "//"와 "\n" 사이에 아무것도 입력하지 않은 경우 **ex) //\n** -> `잘못된 커스텀 구분자 형식입니다.` (공백 혹은 빈 문자는 구분자로 허용하지 않는다.)
- 커스텀 구분자가 숫자인 경우  **ex) //3\n** -> `커스텀 구분자는 문자여야 합니다.` (숫자는 구분자로 허용하지 않는다.)

# 🥋 테스트 해볼 사항 

- 기본 구분자(쉼표, 콜론)와 커스텀 구분자를 포함한 입력이 올바르게 처리되는지 확인합니다.
- 두 자리 이상의 수도 올바르게 처리되는지 확인합니다.  **ex) "10:20,3000" -> 결과 : 3030**
- 입력이 빈 문자열이거나 여러개의 구분자로 이루어졌을 경우 '0'을 반환하는지 확인합니다.  **ex) ",,,,:" and "//;\n;;;,:" -> 결과 : 0**
- 기본 구분자와 커스텀 구분자 모두 포함된 경우에도 올바르게 실행되는지 확인합니다.   **ex) "//;\n1;2,3" -> 결과 : 6**
